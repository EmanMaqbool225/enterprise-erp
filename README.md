Enterprise ERP SystemA secure, high-performance desktop Enterprise Resource Planning system built with Flutter and Dart, featuring local encrypted storage, role-based workflows, and automated system locking.Features and ModulesPoint of Sale (POS): Fast, touch-friendly checkout interface designed for daily retail and commercial operations.Fermentation and Inventory Rooms Management: Specialized tracking system for environmental control and storage management.Advanced Financial Reporting: Real-time cash flow tracking, receipts, vouchers, and ledger monitoring.Secure Local Database: Powered by Drift (SQLite) with encrypted local storage mechanisms.App Lock and Security: Quick-lock mechanism and session integrity checks to protect sensitive business data.Cloud Backup: Automated synchronization service with Google Drive.Tech StackFramework: Flutter (Windows Desktop)State Management and Database: Drift, SQLite, ProviderSecurity and Cryptography: SHA-256 Hashing, Code ObfuscationUI Architecture: Custom adaptive layouts, modern clean dashboard designInstallation and SetupClone the repository:git clone https://github.com/EmanMaqbool225/enterprise-erp.gitNavigate to the project directory:cd enterprise\_erpInstall dependencies:flutter pub getRun the application in release mode:flutter build windows --release --obfuscate --split-debug-info=build/app\_debug\_symbolsSecurity HighlightsBuilt with production-grade code obfuscation to prevent reverse engineering.Isolated local configuration and secure PIN verification.AuthorEman MaqboolCybersecurity and Networks Engineering Undergraduate
